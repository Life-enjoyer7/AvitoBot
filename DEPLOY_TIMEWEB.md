# Деплой на Timeweb Cloud

Timeweb Cloud — российский хостинг: с его IP Яндекс.Маркет, Авито и Mail.ru
работают (в отличие от зарубежного Render, который они блокируют).

Схема: **App Platform** (контейнер с ботом + Mini App, выдаёт бесплатный
HTTPS-домен) + **управляемая PostgreSQL** (хранение данных).

---

## 0. Разово: запушьте код

```bash
git push --force origin main
```

## 1. Создайте базу PostgreSQL

1. Timeweb Cloud → **Базы данных** → **PostgreSQL** → Создать.
2. Выберите минимальный тариф и регион (Москва/СПб).
3. После создания откройте кластер → вкладка **«Подключение»** → скопируйте
   строку подключения (host, port, user, password, database).

Итоговая строка для переменной `DATABASE_URL` (подставьте свои значения):

```
postgresql://USER:PASSWORD@HOST:5432/DATABASE
```

## 2. Создайте приложение

1. Timeweb Cloud → **App Platform** → **Создать приложение**.
2. Подключите ваш GitHub-репозиторий, выберите ветку `main`.
3. В поле **Фреймворк** выберите **Docker Compose**.
4. Выберите регион (тот же, что у базы) и минимальный тариф.
5. **Переменные** (секреты):
   - `BOT_TOKEN` — токен бота от @BotFather;
   - `DATABASE_URL` — строка из шага 1;
   - `WEBAPP_URL` — пока оставьте пустым (заполним на шаге 4).
6. Создайте приложение.

## 3. Узнайте домен приложения

После первого деплоя откройте приложение → вкладка **«Дашборд»**. Там будет
**бесплатный технический домен** вида `https://<имя>.timeweb.cloud`.

Проверьте, что Mini App открывается:

```
https://<домен>/healthz   → должно вернуть {"status":"ok"}
https://<домен>/          → должна открыться страница «Ценолов»
```

## 4. Укажите WEBAPP_URL и передеплойте

1. В приложении → **Переменные** → задайте:
   - `WEBAPP_URL` = `https://<ваш-домен>.timeweb.cloud`
2. Нажмите **Передеплой** (redeploy).

После рестарта бот сам выставит кнопку меню «Открыть приложение».

## 5. Проверка

1. Откройте бота в Telegram → кнопка **«Открыть приложение»** → Mini App.
2. Добавьте ссылку на товар с Яндекс.Маркета (карточку, не каталог) — цена и
   фото должны быть **реальными** (не «оценочно»).
3. Аналогично для Авито.

---

## Примечания

- **Данные с Render не переносятся автоматически** — треки нужно добавить
  заново (или можно перенести вручную из старой PostgreSQL).
- Mini App работает по HTTPS (технический домен Timeweb). При желании можно
  привязать собственный домен.
- `WEBAPP_DEV_MODE=false` уже прописан в `docker-compose.yml` — вход строго
  через Telegram `initData`.
- Ozon / Wildberries здесь всё равно вернут mock: их антибот режет и
  российские дата-центры. Реальные — Авито и Яндекс.Маркет.
