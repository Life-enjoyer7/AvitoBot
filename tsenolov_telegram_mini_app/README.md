# Ценолов — Telegram Mini App UI prototype

Адаптивный интерактивный фронтенд для прототипа сервиса мониторинга цен.

## Запуск локально

Можно открыть `index.html` в браузере. Для более предсказуемого поведения используйте локальный сервер из этой папки:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Что работает в демо

- Адаптивная навигация: обзор, отслеживания, история, уведомления, настройки и помощь.
- Поиск и фильтрация товаров.
- Добавление объявления через модальное окно.
- Просмотр карточки товара, демонстрационной истории цены и целевой цены.
- Пауза / возобновление отслеживания.
- Сохранение демонстрационных данных в `localStorage`.
- Опциональная интеграция с Telegram Web Apps SDK: `ready()`, `expand()`, цвет шапки и имя пользователя.

## Что пока не подключено

Это UI-прототип, а не готовый продакшн-бот: нет backend API, настоящего сбора цен с маркетплейсов, планировщика проверок, отправки уведомлений, авторизации и серверной синхронизации. Все товары и история цен в начальном состоянии демонстрационные. Для публикации как Telegram Mini App потребуется разместить страницу на HTTPS и настроить URL Mini App в Telegram BotFather.
